# Checklist de prueba demo

## Objetivo

Validar English Drops Daily con 10 usuarios reales antes de preparar una
version release. Usar el APK debug y registrar observaciones sin ayudar al
usuario, excepto cuando quede bloqueado.

## 1. Instalacion

- [ ] El APK se instala sin errores.
- [ ] El nombre visible es "English Drops Daily".
- [ ] El icono aparece correctamente.
- [ ] La app abre sin cierre inesperado.
- [ ] La primera carga tarda un tiempo razonable.

## 2. Primera impresion

- [ ] El usuario entiende que esta viendo una microleccion.
- [ ] Identifica la palabra, significado y ejemplo sin explicacion externa.
- [ ] La cantidad de acciones visibles no resulta abrumadora.
- [ ] El texto se lee correctamente en su pantalla.
- [ ] No encuentra textos tecnicos o mensajes confusos.

## 3. Navegacion

- [ ] Encuentra el menu principal.
- [ ] Encuentra Favoritos.
- [ ] Encuentra Progreso.
- [ ] Encuentra Configuracion.
- [ ] Puede regresar a la microleccion sin perderse.

## 4. Swipe y siguiente leccion

- [ ] Descubre la ayuda de gestos.
- [ ] Puede avanzar deslizando.
- [ ] Puede volver a la leccion anterior.
- [ ] El boton "Siguiente" funciona.
- [ ] Durante la prueba no aparecen repeticiones mientras quedan entradas nuevas.
- [ ] La tarjeta responde sin saltos, bloqueos ni contenido cortado.

## 5. Audio

- [ ] "Escuchar" reproduce una pronunciacion en ingles.
- [ ] El volumen es suficiente.
- [ ] La velocidad elegida en Configuracion se aplica.
- [ ] Si TTS no esta disponible, aparece un error comprensible.
- [ ] La app sigue funcionando despues de un fallo de audio.

## 6. Ejercicios

- [ ] El usuario encuentra "Practicar".
- [ ] Entiende como elegir una respuesta.
- [ ] Ve claramente si la respuesta es correcta o incorrecta.
- [ ] Puede leer la explicacion.
- [ ] Ve el resultado final.
- [ ] Puede volver al inicio o practicar otra vez.

## 7. Gota del dia

- [ ] "Gota del dia" se distingue de las acciones normales.
- [ ] Abre una experiencia especial.
- [ ] La leccion contiene contexto y mini reto.
- [ ] El usuario entiende por que es diferente.

## 8. Favoritos

- [ ] Puede guardar una leccion.
- [ ] Recibe confirmacion al guardarla.
- [ ] Encuentra la leccion desde Favoritos.
- [ ] El favorito permanece despues de cerrar y abrir la app.

## 9. Progreso y racha

- [ ] El progreso cambia despues de estudiar.
- [ ] Una practica completada actualiza las estadisticas.
- [ ] La racha se muestra y se entiende.
- [ ] Cerrar y abrir la app conserva el progreso.

## 10. Notificaciones

- [ ] Encuentra la configuracion de notificaciones.
- [ ] Entiende las opciones de frecuencia.
- [ ] Android solicita permiso cuando corresponde.
- [ ] Si rechaza el permiso, la app explica como resolverlo.
- [ ] Puede activar y desactivar el horario silencioso.
- [ ] Las horas "Desde" y "Hasta" se guardan.
- [ ] Una notificacion abre la leccion correcta al tocarla.
- [ ] No recibe notificaciones durante el horario silencioso.

## 11. Estabilidad

- [ ] No hay cierres inesperados.
- [ ] No hay pantallas vacias permanentes.
- [ ] No hay botones que parezcan activos y no respondan.
- [ ] No hay texto cortado o superpuesto.
- [ ] La app funciona sin conexion a internet.
- [ ] La rotacion o cambio de tema no rompe el flujo.
